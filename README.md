# Watchlist

A program to keep track of all TV shows and movies that I need to watch, that also gives me upcoming releases,
audience ratings, and potentially reminders to watch.

## Project Goal

I love TV shows and Movies, but it is hard for me to keep track of everything I want to watch. I also want know when
a show or movie series that I love has an upcoming release and or the ratings of that show or movie.

## MVP Scope

The MVP needs to be able to search movies and TV shows and add them to a list. That list needs to also be able to remove, mark as finished, and reorder.

## Future Plans

You should be able to make multiple watchlists.

You should be able to select one show or movie and see info on it. For shows, you should be able to see how many seasons there are, the ratings for each season, the overall rating, and if there is upcoming releases, as well as year of release. For movies, you should be able to see the audience ratings, and if there is upcoming releases in that movie series, as well as year of release.

You should be able to set reminders to watch something.
